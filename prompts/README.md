# Interview Prompts

This folder contains prompts for different types of interviews.

## Available Prompts

- `bq_interview.md` - Behavioral Question (BQ) interview prompt

## Usage

Prompts are loaded and used by the API to initialize conversation context. Each prompt defines the AI's role, behavior, and interview style.

## Adding New Prompts

1. Create a new markdown file in this folder
2. Define the interview type, guidelines, and conversation style
3. Update the API to load and use the new prompt
